RetailPulse

  • BigQuery
  • Airflow
  • dbt
  • Pub/Sub
  • Apache Beam
  • Python

A practice project on Google Cloud. It simulates an e-commerce data platform with batch and streaming pipelines. Batch data comes from two public APIs and goes to Cloud Storage and BigQuery, then dbt cleans it. Streaming events come from a Python script through Pub/Sub and Beam into BigQuery, and that part runs locally. Airflow runs the batch steps.

Batch (Airflow runs the steps)

  1. Two public APIs
  2. Python extract
  3. Cloud Storage
  4. BigQuery Bronze
  5. dbt Silver
  6. dbt Gold

Streaming (runs locally)

  1. Python event publisher
  2. Pub/Sub
  3. Beam (DirectRunner)
  4. BigQuery Bronze
  • 8 dbt models and 49 tests. 47 pass and 2 warn, because 30 orders in the source data have no date. I left that visible on purpose.
  • Loads are safe to rerun. Each run deletes and inserts by run date, so reruns do not create duplicates.
  • Planned, not built: a Looker Studio dashboard, and running Beam on Dataflow.
